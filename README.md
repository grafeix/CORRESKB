# Ligne K vers CDG 1

Site mobile affichant le train de la ligne K prévu à 08:10 entre Gare du Nord et Aulnay-sous-Bois, puis les deux prochains RER B directs vers Aéroport Charles-de-Gaulle 1.

## Installation sur GitHub Pages

1. Déposer `index.html`, `style.css` et `app.js` à la racine du dépôt.
2. Ouvrir **Settings > Pages**.
3. Choisir **Deploy from a branch**.
4. Sélectionner la branche **main** et le dossier **/(root)**.
5. Enregistrer puis attendre la fin du déploiement dans l'onglet **Actions**.

## Avertissement

La clé API PRIM est volontairement placée dans `app.js`. Elle est donc publique et visible par toute personne consultant le site.
